# Tsukushi: A 64-bit RISC-V Application Processor

Tsukushi (筑紫) is (eventually) a free and open-source 64-bit RISC-V application
processor project. The hardware design of Tsukushi is written in [Veryl] as we
believe that it is a balanced choice between modern developer experience and
interoperability with legacy components. The hardware design and associated
software of Tsukushi are licensed under weakly-reciprocal licenses so that you
can integrate Tsukushi into your project without worries while we can keep
Tsukushi free and open-source.

## Status

We are working on Eboshi (烏帽子), the first microarchitecture of Tsukushi.
Eboshi will be an in-order uniprocessor supporting a subset of RVA23.
